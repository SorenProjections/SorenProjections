## Featured project

### [AgentDesk](https://github.com/SorenProjections/AgentDesk)

A local workspace for coordinating multiple AI agents such as Codex, Antigravity, and WorkBuddy.

It supports scheduled prompts, task queues, dependency-based follow-ups, native session monitoring, and completion notifications — designed to make long-running agent workflows easier to manage without constantly watching the screen.
