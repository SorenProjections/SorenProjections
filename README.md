## Featured projects

### [AgentDesk](https://github.com/SorenProjections/AgentDesk)

A local workspace for coordinating multiple AI agents such as Codex, Antigravity, and WorkBuddy.

It supports scheduled prompts, task queues, dependency-based follow-ups, native session monitoring, and completion notifications — designed to make long-running agent workflows easier to manage without constantly watching the screen.

### [novel-workbench](https://github.com/SorenProjections/novel-workbench)

An AI workbench for long-form fiction with structured planning, deterministic context assembly, human review, state tracking, and multi-model support.

It explores how to make long-horizon LLM workflows more controllable and reliable by separating planning, generation, review, validation, and authoritative state updates.
